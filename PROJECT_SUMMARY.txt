🚀 DEPLOYMENT PATH
═══════════════════════════════════════════════════════════════════════════

LOCAL DEVELOPMENT (5 minutes)
  1. npm install
  2. npm run dev
  3. Visit http://localhost:3000

GITHUB PUSH (5 minutes)
  1. git init
  2. git add . && git commit -m "Initial commit"
  3. Push to GitHub repository

VERCEL DEPLOYMENT (2 minutes)
  1. Sign up at vercel.com with GitHub
  2. Import repository
  3. Click Deploy
  4. Live! 🌍

Result: Your site is live at [project].vercel.app

🎯 CUSTOMIZATION OPTIONS
═══════════════════════════════════════════════════════════════════════════

Add More Protocols:
→ Edit src/data/protocols.ts
→ Add new protocol object with all fields
→ Auto-integrated in sidebar & navigation

Change Colors:
→ Update protocol.color in protocols.ts
→ Or modify tailwind.config.js for global colors

Add 3D Models:
→ Replace ProtocolViewer.tsx placeholder
→ Support for Three.js, Babylon.js, or custom WebGL

Update Content:
→ Modify text in protocols.ts
→ Update component descriptions
→ Add new learning resources
